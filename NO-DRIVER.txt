v0.5.0 — Windows 기본 입력 시험 버전

이 버전은 Windows user32 SendInput으로 마우스와 키보드를 입력합니다.
Interception 라이브러리/드라이버를 호출하거나 설치하지 않습니다.
기존 드라이버를 자동으로 제거하지는 않습니다.
게임에서 이 입력을 실제로 받는지는 사용자 PC에서 시험해야 합니다.
빌드·규칙 테스트 통과와 실게임 입력 성공은 별개입니다.

작은 업데이트(abyss-auto-no-driver-update)를 받은 경우:
1. 현재 어비스 프로그램을 종료합니다.
2. ZIP의 AbyssAuto.dll을 기존 AbyssAuto.exe 폴더에 복사해 덮어씁니다.
3. 기존 AbyssAuto.exe를 실행해 제목 0.5.0과 Windows 기본 입력 표시를 확인합니다.
4. 기존 설정·이미지·런타임은 그대로 사용합니다.

전체 패키지(abyss-auto-no-driver)는 압축을 풀어 AbyssAuto.exe를 실행합니다.
게임과 프로그램의 권한 수준을 맞추세요. 현재처럼 관리자 권한 실행을 사용할 수 있습니다.
처음에는 목표 1판으로 ESC·클릭·SPACE 및 화면 전환을 확인합니다.
기본 입력을 게임이 받지 않으면 오류 정지합니다. 자동으로 드라이버 방식으로 돌아가지 않습니다.

다른 게임에서 기존 Interception 드라이버가 실행되면 안 되는 경우:
기존 공식 설치 도구의 /uninstall로 제거하고, 제거 성공을 확인한 뒤 재부팅해야 합니다.
DLL 파일 삭제나 이 버전 실행만으로 이미 설치된 드라이버가 제거되지 않습니다.
제거·재부팅 후에도 이 버전은 드라이버 설치 없이 실행할 수 있는 구조입니다.
그 상태에서 게임 입력이 동작하는지 최종 확인해야 합니다.

정지/종료:
F10은 자동화 정지입니다. X는 입력을 해제한 뒤 창을 자동으로 닫습니다.
트레이 숨김, 백그라운드 서비스, 자동 시작 등록, 별도 입력 프로세스는 없습니다.
프로그램 파일은 디스크에 남지만 창이 완전히 종료된 후 자동 입력을 보내지 않습니다.
Windows의 기존 다른 소프트웨어/드라이버 상태까지 이 앱이 보증하지는 않습니다.
